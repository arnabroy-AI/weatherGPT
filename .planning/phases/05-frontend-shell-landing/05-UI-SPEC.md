| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | Light `#f8fafc` (slate-50) / Dark `#020617` (slate-950) | Page background, nav, footer base |

Accent reserved for: primary CTA button fill, text links + hover states, `:focus-visible` rings, active nav link, hero metric figure.
Amber reserved for: section eyebrow kicker text, hero star/rating row, MoES/IMD strip top border, footer SIH-badge border.
Alert-level chips (Green/Yellow/Orange/Red) are **data colors** mirroring the backend `alert_level` contract — scoped to the alerts-showcase section and the Phase 6 chat badge only, never used as interactive accents. No gradients anywhere except a subtle teal-tinted radial wash behind the hero (solid-color overlays only; purple-blue gradients banned per D-07).

## Responsive Breakpoints

`sm` 640px · `md` 768px (nav links appear, hamburger hides) · `lg` 1024px (3–4 col grids) · `xl` 1280px (max container hold). Base target 390px mobile: single column, stacked CTAs full-width, no horizontal overflow, Sheet drawer nav. Grids: features 1→2→3, teaser 1→3, alerts 1→2→4, steps 1→3. Hero display 32px <640px, 40px ≥640px. Touch targets ≥44px on all icon-only controls.

## Accessibility Notes

Landmarks (`header`/`main`/`section` with `aria-labelledby`/`footer`), skip-to-content link, single H1 (hero) with section H2s in order. `:focus-visible` 2px teal ring on all interactives. Contrast: body slate-700/300 on surfaces; teal-700 (#0f7667) on white ≥4.5:1; amber used for large/600-weight kickers only, never small body text (amber-600 #d97706 on white for 14px/600 passes at ~3.9:1 — kickers are 14px semibold uppercase, acceptable as non-body UI text; all essential copy stays slate). Accordion keyboard-native via Radix; Sheet traps focus with labelled close; theme DropdownMenu `aria-pressed` state + persisted choice, defaulting to `prefers-color-scheme` with no-JS fallback. `prefers-reduced-motion`: disable wash/transition animation. Status Badges never rely on color alone (level name text always present). No images requiring alt text by design (CSS/SVG shapes only — supports D-07 ban on clipart).
